# Оно тебе надо

Одностраничный сайт учебного аукциона «Оно тебе надо». Проект выполнен на HTML и CSS. Для вёрстки использованы Grid Layout и Flexbox.

Для локального просмотра откройте `index.html` в браузере. Сборка и установка зависимостей не требуются.
